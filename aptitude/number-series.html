Number Series

By Navneet Sir | Viral Maths | Complete Missing Number Series

What is a Number Series?

  • Numbers arranged in a sequence following a Definite Rule / Pattern
  • If there's no definite rule → it's NOT a number series (random numbers)
  • We must be able to find the next number based on that rule
Imp: In exams, if a series follows a pattern, it's a Number Series. Random numbers like 4, 10, 199, 1298 → NOT a series because no rule connects them!

Criteria for a Valid Number Series

  • 1 Must have a Definite Rule binding the numbers
  • 2 We must be able to Find the Next Number using that rule

Example: Valid Series

4, 6, 10, 16, 24, ___

Gaps: +2, +4, +6, +8 → next gap +10 → 34

Types of Number Series (based on question)

TypeDescription
Missing Number SeriesOne number is missing in the sequence → find it
Wrong Number SeriesOne number is placed incorrectly → find the wrong one

Types of Series (based on Movement)

  • Slow Series → Check Differences (Gap)
  • Fast Series → Check Product (Multiplication)

Calculation Techniques

Addition — Rounding Method

749 + 398 = 749 + 400 − 2 = 1149 − 2 = 1147

867 + 499 = 867 + 500 − 1 = 1367 − 1 = 1366

Rule: Round to nearest 100, add, then adjust (add/subtract the difference)

Addition — Left-to-Right Method

456 + 349 → 400+300=700, 50+40=90, 6+9=15 → 805

1539 + 648 → 1500+600=2100, 40+30=2170, 9+8=17 → 2187

Subtraction — Nadiya Paar Approach

784 − 699 → 700−699=1, 784−700=84 → gap = 85

1248 − 996 → 1000−996=4, 1248−1000=248 → 252

Nadiya Paar: Compare both numbers to the nearest 100/1000, then add the gaps!

Subtraction — Partition Approach

Split into two parts (leave 2 places):

2435 − 1929 → Gap(24,19)=5 → Gap(35,29)=6 → 506

7621 − 4819 → Gap(76,48)=28 → Gap(21,19)=12 → 2812

When 2nd part is smaller (e.g., 2716 − 1919), reduce 1st part by 1 and add 100 to 2nd part: Gap(27,19)=→7 (but write 6), Gap(16,19)=−3 → 100−3=97 → 797

Multiplication — Left-to-Right

87 × 7 → 7×8=56, 7×7=49 → 56+4=60, carry 9 → 609

36 × 4 → 4×3=12, 4×6=24 → 12+2=14, carry 4 → 144

69 × 9 → 9×6=54, 9×9=81 → 54+8=62, carry 1 → 621

How to Find the Pattern?

For Slow Series → Check Differences

  • Find gap (difference) between consecutive terms
  • If gap doesn't reveal pattern → Double Difference (Difference of differences)

For Fast Series → Check Product

  • Check if numbers are being multiplied
  • If product alone doesn't match → Product + Addition/Subtraction
Slow → Difference (single/double)
Fast → Product (maybe + some adjustment)

Pattern Type 1: Basic Patterns

Even Number Series

2, 4, 6, 8, 10, ___ → 12 (gap of 2)

Odd Number Series

1, 3, 5, 7, 9, ___ → 11 (gap of 2)

Prime Number Series

2, 3, 5, 7, ___ → 11

Very important! 2,3,5,7 → looks like odd numbers, but it starts with 2 (not 1). Always check if it's Prime not just Odd! Students often write 9 (odd) instead of 11 (prime).

Skipped Prime Series

3, 7, 13, 19, ___

3 → skip 5 → 7 → skip 11 → 13 → skip 17 → 19 → skip 23 → 29

Imp: 3, 7, 17, ___
Skip 1 prime (5), then skip 2 primes (11,13) → next skip 3 primes (19,23,29) → 31

Consecutive Cubes

Cube of Prime Numbers

8, 27, 125, 343, ___

2³, 3³, 5³, 7³ → 11³ = 1331

Prime cubes pattern: 2,3,5,7,11,13,... (primes). Recognizing this saves time!

Pattern Type 4: 10 + Prime Series

12, 13, 15, 17, ___

10+2=12, 10+3=13, 10+5=15, 10+7=17 → 10+11 = 21

Think: Break each number as "10 + prime". The primes increase: 2,3,5,7,11...

Pattern Type 5: Fibonacci-like (Sum of Previous)

1, 3, 4, 8, 15, 27, ___ ★★★★★

  • 1+3+4=8, 3+4+8=15, 4+8+15=27 → 8+15+27 = 50
This is called the Fibonacci-like Series. The Fibonacci sequence is found in nature — galaxies, sunflowers, etc. In exams, this pattern uses sum of previous 3 terms!

Pattern Type 6: Product Series

× 1.5 Pattern

2, 3, 4.5, 6.75, ___

2 × 1.5 = 3, 3 × 1.5 = 4.5, 4.5 × 1.5 = 6.75 → 6.75 × 1.5 = 10.125

× Increasing Multiplier

7, 14, 42, 168, 840, ___

7×1=7, 7×2=14, 14×3=42, 42×4=168, 168×5=840 → 840×6 = 5040

Pattern Type 7: Double Difference (MMS Series)

5, 12, 27, 58, 121, ___ ★★★★★

Step 1: Find 1st difference → 7, 15, 31, 63 (no clear pattern)
Step 2: Find 2nd difference → 8, 16, 32 (doubling!)
Step 3: Next 2nd diff = 64 → Next 1st diff = 63+64 = 127
Answer: 121 + 127 = 248
Also called "Saadi Kinara" / MMS Series (Manish Manorath Series): When 2nd difference creates a pattern (like doubling), it's like the beautiful border design on a saree!

Pattern Type 8: n³ ± n Pattern

n³ − n

0, 6, 24, 60, 120, ___

1³−1=0, 2³−2=6, 3³−3=24, 4³−4=60, 5³−5=120 → 6³−6 = 210

n³ + n (Alternating)

10, 24, 68, 120, ___

2³+2=10, 3³−3=24, 4³+4=68, 5³−5=120 → 6³+6 = 222

When you see numbers close to cubes (like 24=27−3, 120=125−5), check for n³ ± n pattern!

Pattern Type 9: Mixed Cube-Square Series

512, 16, 343, 25, ___

Alternating: 8³=512, 4²=16, 7³=343, 5²=25 → 6³ = 216

Pattern Type 10: "Never Give Up" Series

8, 4, 6, 12, 30, ___ ★★★★★

Pattern: Falls then rises!
8 → ÷2 = 4 → ×1.5 (add half) = 6 → ×2 = 12 → ×2.5 (double+half) = 30 → ×3 = 90
"Never Give Up" → The series drops once, then keeps rising with increasing multipliers: 0.5, 1.5, 2, 2.5, 3, ...

Pattern Type 11: "Blue Hai Pani Pani" Series

15, 14, 19, 11, 23, 8, 27, ? ★★★★★

Two series merged (alternating):
Series 1: 15 → 19 → 23 → 27 → (+4 each) → next = 31
Series 2: 14 → 11 → 8 → (−3 each) → next = 5
Answer: 5
How to identify: Series is long (6+ terms), keeps going up-down-up-down. Split into 2 alternating series!

Pattern Type 12: Triple Series

0, 4, 3, 6, 6, 7, 12, 10, ? ★★★★★

Three series merged!
Series 1: 0 → 6 → 12 → (+6 each) → next = 18
Series 2: 4 → 6 → 10 → (+2, +4, ... )
Series 3: 3 → 7 → ? → (+4 each) → ? = 11
When normal difference doesn't work, check if 3 (or more) patterns are interleaved!

Pattern Type 13: Decimal / Fraction Series

4.5, 16, 5.5, 33, 3.5, 38, 1.5, ? ★★★★

Two series: Decimals: 4.5 → 5.5 → 3.5 → 1.5 (+1, −2, −2)
Other: 16 → 33 → 38 → ? (+17, +5, ...)
Gap pattern for other series: 17 → 5 → −? Check differences of decimals!
Overall next → 25.5

Pattern Type 14: Product + Addition

9, 19, 40, 83, 170, ___

9×2+1=19, 19×2+2=40, 40×2+3=83, 83×2+4=170 → 170×2+5 = 345
Another: 8, 20, 63, 256, 1285, ___
8×2+4=20, 20×3+3=63, 63×4+4=256, 256×5+5=1285 → 1285×6+6 = 7716

Pattern Type 15: Mains Level (Decimal Multiplication)

1898, 949, 22776, 11388, ___ ★★★★★

Pattern: ÷2, ×24, ÷2, ×?
1898 ÷2 = 949, 949 × 24 = 22776, 22776 ÷2 = 11388 → 11388 × 3.6 = ?
The multiplier moves decimal: 2 → 2.4 → 3 → 3.6
11388 × 3.6 = 5694 (shift decimal: 569.4 × 10... check pattern)
In Mains, the decimal point shifts! Always track how many places the decimal moves between terms.

Pattern Type 16: Gap with Table Series

325, 259, 204, 160, 127, 105, ___

Differences: 66, 55, 44, 33, 22 → decreasing by 11 (13-table pattern!)
Next diff = 11 → 94 (Use partition approach to find gaps quickly!)

Check gaps: 66=13×6, 55=13×5, 44=13×4, 33=13×3, 22=13×2, 11=13×1

More Pattern Types from the Video

① Geometric Progression (×3)

1.5, 4.5, 13.5, 40.5, ___

×3 each step → 40.5 × 3 = 121.5

② "Cross 2 + 1" Pattern

1, 3, 7, 15, 31, 63, ___

Pattern 1 (Gaps): +2, +4, +8, +16, +32, +64 → 127
Pattern 2 (×2+1): 1×2+1=3, 3×2+1=7, 7×2+1=15 … 63×2+1 = 127
"Cross 2 + 1" — Very common in exams! Both approaches work. The gaps double each time.

③ Decreasing Multipliers

10, 40, 120, 240, ___

10×4=40, 40×3=120, 120×2=240 → 240×1 = 240

④ Gap Increasing by +2

10, 18, 28, 40, 54, 70, ___

Gaps: +8, +10, +12, +14, +16 → next +18 → 88

⑤ Gap Doubling Pattern

26, 28, 36, 52, 84, ___

Gaps: +2, +4, +8, +16, +32 → next +64 → 148

⑥ Square + n (Multiple Valid Patterns)

3, 7, 13, 21, ___ ★★★★

Pattern 1 (Gaps): +4, +6, +8, +10 → 31
Pattern 2 (Square+n): 1²+2=3, 2²+3=7, 3²+4=13, 4²+5=21, 5²+6=31
A series can have more than one valid pattern! In exams, check which matches the options. Note BOTH in your notes.

⑦ Alternating Cube ± n

10, 24, 68, 120, ___ ★★★★

2³+2=10, 3³−3=24, 4³+4=68, 5³−5=120 → 6³+6 = 222

⑧ Repeating Digits Pattern

1, 11, 111, 1111, ___

One 1, two 1s, three 1s, four 1s → 11111 (five 1s)

⑨ 13-Table Gap Pattern (Previous Year)

325, 259, 204, 160, 127, 105, ___

Gaps: 66, 55, 44, 33, 22 → These are 13×6, 13×5, 13×4, 13×3, 13×2
Next gap = 13×1 = 11 → 105 − 11 = 94

⑩ Alternating +5, −2 Pattern (PYQ)

(Series with alternating +, − pattern) ★★★★

When the series goes up then down then up then down → check for alternating + and − operations.
This is a Previous Year Question pattern. Use gap analysis carefully!
Another Triple Series (Mains Level):
Series: 8, 9, 10, 7, 10, 11, 6, 11, 12, ___ ★★★★★
Series 1 (decreasing): 8 → 7 → 6 → 5 (−1)
Series 2 (increasing): 9 → 10 → 11 → 12 (+1)
Series 3 (increasing): 10 → 11 → 12 → 13 (+1)
Three interleaved APs with ±1. Identify by long length & no single pattern!
