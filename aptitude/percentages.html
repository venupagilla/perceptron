PERCENTAGES

Complete Study Notes — Chapter 1 of Maths

1. Basics & Definitions

Percentage means "per hundred." It expresses a number as a fraction of 100.

Symbol: %

  • % → Fraction: Drop the % sign and divide by 100.
       e.g., 20% = 20/100 = 1/5
  • Fraction → %: Multiply by 100.
       e.g., 1/4 = 1/4 × 100 = 25%
  • % → Decimal: Drop the % sign and move decimal two places left.
       e.g., 45% = 0.45
Navneet Sir's Core Principle: Always identify the BASE (the original whole) correctly. The percentage is always calculated of this base.
Misidentifying the base is the #1 cause of errors!

3. Fast Calculation Tricks

Trick A: Finding 10%, 5%, 1% (The Base Rules)

10% → Move decimal one place left. → 10% of 450 = 45
5% → Half of 10%. → 5% of 450 = 22.5
1% → Move decimal two places left. → 1% of 450 = 4.5
✏️ Example: Find 16% of 325

= 10% + 5% + 1%

= 32.5 + 16.25 + 3.25 = 52

Trick B: "Multiply by 10" Rule for Awkward Percentages

If a % ends in a digit other than 0 or 5, multiply by 10 to make math easy, then divide final answer by 10.

✏️ Example: Find 23% of 60

Instead, find 230% of 60:

• 100% → 60

• 100% → 60

• 30% → 18

• Total 230% → 60 + 60 + 18 = 138

Divide by 10 → Answer = 13.8

Trick C: Percentage of a Percentage

To find X% of Y%, simply multiply them and put a decimal before the last two digits.

✏️ Example: 20% of 30%

= 2 × 3 = 6 → 0.06 (or 6%)

Trick D: Navneet Sir's "Splitting" Method

Break down complex % into sums/differences of memorized fractions.

✏️ Example 1: Find 37.5% of 240

Recognize 37.5% = 3/8 (from table).

Calculation: 240 ÷ 8 × 3 = 30 × 3 = 90

✏️ Example 2: Find 62.5% of 480

Recognize 62.5% = 5/8.

Calculation: 480 ÷ 8 × 5 = 60 × 5 = 300

4. Successive % Change (The AB Rule)

When a value changes by a% and then by b%:

Net % Change = a + b + (a × b) / 100

• If result is positive (+) → net increase
• If result is negative (−) → net decrease
✏️ Example 1: ↑20%, then ↑30%

= 20 + 30 + (20 × 30)/100 = 50 + 6 = 56% Increase

✏️ Example 2: ↑20%, then ↓20%

= 20 + (−20) + (20 × −20)/100 = 0 − 4 = 4% Decrease

↑20% then ↓20% is NEVER 0%! It is always a net decrease.

Mega Shortcut for Same % Increase & Decrease

If ↑x% then ↓x% (or vice versa), net loss = x² / 100 %

Example: ↑10% then ↓10% → Net loss = 10² / 100 = 1% loss
📊 AB Rule Visual Flow
Exam Application (Navneet Sir's Tip): This is frequently tested in questions about price changes, marks, or dimensions where two successive % changes occur. Always apply the AB rule directly instead of calculating step-by-step.

5. Percentage Point vs. Percent Change

Examiners love to trick you here! Read carefully!

Percentage Point = Simple subtraction of two percentages.

Percent Change = Change relative to the OLD base value.
✏️ Example: Pass % in 2022 = 40%, in 2023 = 60%

• Increase in Percentage Points: 60% − 40% = 20 Percentage Points

• Percent Increase in pass rate: (60 − 40)/40 × 100 = 20/40 × 100 = 50% Increase

In Data Interpretation (DI): Graphs often show "percentage point change." Don't mistake it for "percent change"!

6. Expenditure & Consumption Concept

Connects Price, Consumption (quantity used), and Expenditure.

Expenditure = Price × Consumption

If Expenditure remains Constant, Price and Consumption are inversely proportional.
P₁/P₂ = C₂/C₁
✏️ Example: Price of sugar ↑ by 25%. By what % must consumption ↓ to keep expenditure same?

Let Old Price = 100, New Price = 125.

100 × C₁ = 125 × C₂

C₂/C₁ = 100/125 = 4/5

Consumption reduced by 1/5 = 20% decrease

Navneet Sir's Shortcut: If price increases by R%, to keep expenditure constant, consumption must decrease by:

R / (100 + R) × 100%

Here, R = 25 → Decrease = 25/125 × 100 = 20%

7. Elections & Votes Concept

Valid Votes = Total Votes − (Invalid Votes + Not Voted)

Winner's Margin = (Winner's Valid Votes) − (Loser's Valid Votes)

Standard Setup

  • Let Total Votes = 100%
  • Winning candidate gets x%
  • Losing candidate gets y%
  • Difference = (x − y)%
  • This difference (x − y)% of Valid Votes = Margin given in question
✏️ Example: Two candidates got 40% and 30% of valid votes. Winner won by 500 votes. Find total valid votes?

Difference in % = 40% − 30% = 10%

10% of Valid Votes = 500

Valid Votes = 5000

Advanced Pattern (Navneet Sir): Questions may involve three candidates or ask for total population (including those who didn't vote). Always carefully parse the given data to find the correct base — Total Votes vs. Valid Votes vs. Population.

8. Population Growth/Decline Formula

P_final = P_initial × (1 ± R/100)ⁿ

Use + for Growth/Increase.
Use − for Decline/Decrease.
n = Time (usually in years)
✏️ Example: Pop. = 10,000. ↑10% every year. Find pop. after 2 years?

P = 10000 × (1 + 10/100)²

= 10000 × (11/10)²

= 10000 × 121/100 = 12,100

Navneet Sir's Variant — "Present Population" Problems:
If the population after n years is P, and the annual growth rate is R%, then:
Present Population = P / (1 + R/100)ⁿ

9. Faulty Weight / Dishonest Dealer

Profit % = (Error / (True Value − Error)) × 100

Error = True Weight − False Weight
✏️ Example: Shopkeeper gives only 900g instead of 1 kg (1000g). Find profit %?

Error = 1000 − 900 = 100g

Profit % = (100 / (1000 − 100)) × 100 = (100/900) × 100 = 11.11% profit (or 1/9 × 100)

Shortcut: If he uses x grams instead of 1000g:
Profit % = ((1000 − x) / x) × 100
Advanced Case (Navneet Sir): If he also marks up the price by M% and gives a discount of D%, combine the profit from false weight with markup-discount profit.

Total Profit % = [ (100+M)(100−D) / 100 ] − 100 + (Profit from false weight)

10. Income, Expenditure & Savings

Income = Expenditure + Savings
✏️ Example 1 (Base is Income): Man spends 70% of income. Income ↑20%, Exp ↑10%. Find % change in savings?

Assume Income = 100 → Exp = 70, Savings = 30.

New Income: 120

New Exp: 70 + 70×10% = 70 + 7 = 77

New Savings: 120 − 77 = 43

% Change: (43 − 30)/30 × 100 = 13/30 × 100 = 43.33% Increase

✏️ Example 2 (Base is Expenditure — TRICKY!): Man saves 20% of income. If expenditure = ₹4000, find income?

If he saves 20%, he SPENDS 80%. (Because 20 + 80 = 100)

80% of Income = 4000

Income = 4000 / 80 × 100 = ₹5000

Navneet Sir's "Series" Questions: "If income ↑20% then ↓20%, what is the net change in savings if expenditure remains constant?" — Apply the successive percentage rule to income first, then analyze impact on savings.

QUICK REVISION CHEAT SHEET

Master Formula Summary

1. % → Fraction: ÷ 100  |  Fraction → %: × 100  |  % → Decimal: ÷ 100
2. Net % Change (AB Rule): a + b + (ab)/100
3. Same ↑x% then ↓x%: Net loss = x²/100 %
4. Expenditure = Price × Consumption (inverse if constant)
5. Consumption decrease = R/(100+R) × 100%
6. P_final = P_initial × (1 ± R/100)ⁿ
7. Present Pop = P / (1 + R/100)ⁿ
8. Faulty Weight Profit = (Error/(True−Error)) × 100
9. Income = Expenditure + Savings
10. Valid Votes = Total − (Invalid + Not Voted)

Top Exam Tips

1. Always identify the BASE before calculating %.
2. For successive changes, use the AB rule — never go step-by-step in exams.
3. Memorize the Golden Fraction Table — saves 80% calculation time.
4. In DI, watch out for percentage points vs. percent change — they are different!
5. For dishonest dealer, combine false weight profit with markup-discount when both are given.

Most Common Mistakes

1. Thinking ↑x% then ↓x% gives 0% — it gives a net decrease of x²/100%!
2. Confusing "saves 20%" with "spends 20%" — If savings = 20%, then spending = 80%.
3. Using Total Votes instead of Valid Votes in election problems.
4. Forgetting to reverse the formula for "Present Population" problems — divide instead of multiply!
