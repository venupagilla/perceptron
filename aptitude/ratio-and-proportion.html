Ratio & Proportion

Complete Exam Notes (GATE / Bank PO / SSC / RRB)

1. Essence of Ratio

Ratio = comparison of two quantities by division. a : b or a/b

  • Ratio = Fraction in disguise. Every fraction operation applies.
  • Units MUST match! Never compare kg to cm. If incompatible → answer is CND.
  • "Secret of x": Multiply ratio (4:5) by x → (4x, 5x) converts relative parts to real quantities.
  • Ratio unchanged if both terms multiplied/divided by same non-zero number: a:b = ka:kb
  • Simplify by dividing both by HCF. Example: 24:36 → HCF=12 → 2:3
Ratio of 2 kg to 500 g → 2 kg = 2000 g → 2000:500 = 4:1

2. Types of Ratios

Compound ratio of 2:3, 4:5, 6:7 = (2×4×6):(3×5×7) = 48:105 = 16:35

3. Comparing Ratios

Cross-multiply: If ad > bc → a:b > c:d | If ad < bc → a:b < c:d | If ad = bc → equal
Shortcut: Convert all ratios to decimals and compare — faster under time pressure!

4. Internal Gap Rule (Ratio Arithmetic)

You CANNOT add/subtract ratios until internal vertical gaps are equalized.

Subtract 3:5 from 7:11:
Gap1 = 2, Gap2 = 4. Harmonize: ×2 → 6:10 & 7:11 (both gaps = 4)
Subtract: 7−6 = 1, 11−10 = 1 → Result = 1:1

5. Dividing a Quantity in Given Ratio

If N divided in a:b:c → Part1 = N×a/(a+b+c), Part2 = N×b/(a+b+c), Part3 = N×c/(a+b+c)
Divide ₹140 in 2:3 → Sum = 5 units = ₹140 → 1 unit = ₹28
Parts = ₹56 and ₹84
If a ratio changes after adding/removing a fixed quantity, always let original quantities be kx and ky, then form equation from the condition.

6. Proportion — Basics

a : b :: c : d → a × d = b × c (Product of extremes = Product of means)

a, d = extremes; b, c = means

8. Componendo-Dividendo (Very Important!)

If a:b = c:d, then:

RuleStatement
Invertendob:a = d:c
Alternendoa:c = b:d
Componendo(a+b):b = (c+d):d
Dividendo(a−b):b = (c−d):d
Componendo & Dividendo(a+b)/(a−b) = (c+d)/(c−d)
If (3x+2y)/(3x−2y) = 5, find x:y
3x+2y = 5(3x−2y) → 3x+2y = 15x−10y → 12y = 12x
x:y = 1:1

9. Merging Ratios (3 Variables)

When merging A:B and B:C, the common B (“Bahurupiya” — disguised element) must be equalized!

MethodNicknameBest For
LCM of common termBahurupiyaUniversal — always works
Multiply vertically, diagonally, verticallyUlta-N (Speed)Only A:B and B:C chains
Ulta-N FAILS for A:B and A:C form (same first term)! Use Bahurupiya/LCM instead.
A:B = 2:3, B:C = 4:5
LCM of 3,4 = 12 → A:B = 8:12, B:C = 12:15
A:B:C = 8:12:15

10. Equation Shortcuts (2A = 3B = 4C)

Method 1: "Latkan" (Hanging Numbers)

1. LCM of coefficients (2,3,4 → 12)
2. Divide: A/6, B/4, C/3
3. Denominators = Ratio: A:B:C = 6:4:3

Method 2: "Luka Chupi" (Hide & Seek)

Hide target, multiply remaining coefficients:
A → 3×4=12 | B → 2×4=8 | C → 2×3=6 → 12:8:6 → 6:4:3

11. Fractional Ratios

1/2 : 1/3 : 1/4 → LCM of denominators (2,3,4) = 12 → multiply all → 6:4:3

12. Advanced Merging (4 Variables)

"Zameen Kabza" (Plot Grab): Arrange in matrix; empty cells filled by copying nearest horizontal neighbor; multiply columns vertically.

"Sandwich" Method: Bread (outermost): first/last columns straight down. Potato (inner): multiply diagonally-vertically.

13. "Mahabharata" Shortcut — First & Last Term Only

When only need A:D from chain (A:B, B:C, C:D...):
1. Left column (“Kauravas”): all first terms
2. Right column (“Pandavas”): all second terms
3. Cross-cancel common factors, then multiply
4. Result = Product Left : Product Right = A:D

15. Coin-Based Problems

Golden Rule: Match ratio type to total type!
Total = Value (₹) → ratio in Value terms
Total = Count → ratio in Coin terms
₹55 total. Coins (50p, 25p, ₹1) in count-ratio 5:8:1.
Value ratio: 5×0.5 : 8×0.25 : 1×1 = 2.5:2:1
Sum = 5.5 units = ₹55 → 1 unit = ₹10
Value of 25p coins = 2×10 = ₹20 → count = 20/0.25 = 80 coins

16. Income & Expenditure ("Panda" Method)

Works even when savings are unequal!
1. Write Income ratio on top, Expenditure ratio middle, Savings values bottom
2. Cross-multiply Income × Expenditure → "Ratio Gap"
3. Cross-multiply Expenditure × Savings → "Value Gap"
4. Equate Ratio Gap = Value Gap to solve

17. "Success Ladder" — Year-Over-Year Scaling

Current Value = Old Value × (New Ratio Term / Old Ratio Term)

Think of Old Ratio Term as the rung you're stepping FROM, New as the rung you're climbing TO.

Common Mistakes to Avoid

1. Comparing quantities without same unit
2. Writing “4:1 kg” — ratio has NO unit!
3. Confusing ratio (a:b) with proportion (a:b :: c:d)
4. Sign errors in dividendo
5. Combining ratios without LCM of common term
6. Not assigning common multiplier x in word problems
7. Applying Ulta-N to A:B and A:C form
8. Mixing up count-ratio vs value-ratio in coin problems
